# Font licenses

- `mts_cyrillic_caps.ttf` (composeResources/font) is a modified version of Russo One by Jovanny Lemonad, under the
  SIL Open Font License 1.1 (`RussoOne-OFL.txt`). Changes: subset to Latin and Cyrillic, every lowercase letter drawn
  as its capital, condensed to 82 % width and 96 % height to match Gang of Three (kerning dropped), and renamed to "MTS Cyrillic Caps" because "Russo" is a Reserved Font Name. Russian and the other
  Cyrillic languages use it for titles instead of Gang of Three, which has no Cyrillic letters.
- `go3v2.ttf` is Gang of Three by Vic Fieger. The å and Å were added by hand (the A with the ring of the degree sign).
