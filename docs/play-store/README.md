# Google Play store listing

Everything that goes into the Play Console store listing of the «MTS» app, in its 8 languages (en, es, fr, it, de, sv, nl, ru).

| Path | What | Size |
|---|---|---|
| [listing.md](listing.md) | Name, short and full description of each language | |
| `phone/<lang>/` | Phone screenshots, 8 per language | 1080 × 1920 |
| `tablet/<lang>/` | Tablet and Chromebook screenshots, 6 per language (the same set as the phone without 6 and 7) | 1920 × 1080 |
| `feature-graphic/<lang>.png` | Feature graphic | 1024 × 500 |

The images live in Git LFS (see `.gitattributes`). The ones here are those uploaded to Play Console on 16 November 2026.
